# ПР2 — Знакомство с Docker

Поиск и загрузка образов из Docker Hub, запуск контейнеров, установка ПО внутри контейнера
и создание нового образа командой `commit`.

`terminal-log.txt` — полный журнал выполнения команд с выводом.

Ключевой результат: образ на базе `alpine` (13.6 МБ) с установленным Apache 2.4.68
занял 30 МБ — прирост соответствует объёму установленных пакетов, что подтверждает
слоистую организацию образов.
