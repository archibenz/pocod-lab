# ЛР5 — Apache JMeter, часть 2

Доработка тест-плана: переменная `Server`, данные из `urls.csv`,
проверка Response Assertion на слово «Яндекс», три таймера, четыре Listener.

## Запуск

```bash
jmeter -n -t testplan.jmx -l results.jtl    # urls.csv должен лежать рядом
jmeter -g results.jtl -o report
```
